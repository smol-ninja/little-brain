# Wordmark

The displayed name is `littlebrain`, without a hyphen. It uses Neuropolitical Regular by Raymond Larabie beside the blue glass logo. Chat titles, counters, and controls use the system font.

`Assets/Wordmark.pdf` contains the outlined lettering for the app. The app draws it in the system text color and announces its name to VoiceOver. The SVGs in `docs/` contain the same lettering for GitHub's light and dark themes. These assets contain no font software or font references.

The source is Neuropolitical Regular, PostScript name `Neuropolitical-Regular`, from Typodermic's official `typodermic-free-fonts-2026i.zip`, retrieved on 2026-10-26. Its Desktop EULA v260817, sections 2.2 and 2.3, permit finished logos and outlined artwork without embedded font software. The OTF is outside the repository and app bundle.
