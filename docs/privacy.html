Privacy policy

Effective 16 November 2026

Littlebrain does not require an account, show ads, or sell your information.

The website

Visitor analytics

Umami Cloud records page views and clicks on Download for Mac without cookies. The tracker runs on smol-ninja.github.io and strips query strings and fragments from the URLs it records.

Analytics can include the page path, referrer, browser, operating system, device type, language, screen size, and approximate location. Umami uses IP addresses to create visitor IDs and estimate location. It leaves IP addresses out of analytics records, though Umami and its providers may keep them in operational or security logs. See what Umami measures and its privacy policy.

Downloads and GitHub

GitHub Pages hosts the site, and GitHub Releases hosts the installer. The home page asks GitHub for the latest release so the download link can point to a newer installer when one is available. GitHub's privacy statement covers how it handles these requests.

The app

Local Codex data

Littlebrain reads the local Codex socket at ~/.codex/ipc/ipc.sock and the catalog at ~/.codex/state_5.sqlite. It shows chat titles, which chats are running, and which have unread replies. Selecting a chat opens it in Codex.

Littlebrain keeps its chat tracking file at ~/Library/Application Support/little-brain/tracking.json so it can resume after a restart. It also remembers whether you've seen the welcome panel and enabled Launch at login. The app keeps Codex data and its tracking file on your Mac. It has no analytics or crash reporting.

Update checks

Sparkle checks a signed update feed on GitHub Pages about once a day while Littlebrain is running. You can also check by clicking the version number. The app turns off Sparkle's optional system profiling.

Sparkle downloads updates from GitHub Releases and verifies their signatures. Automatic downloads and installation are off by default. You can turn them on in the update window.

Changes

If this policy changes, we will update this page and the effective date at the top.

Contact

For privacy questions or requests, open an issue on GitHub. Issues are public, so leave out personal information and chat contents.
