Privacy policy

Effective 16 November 2026

littlebrain is a macOS menu bar app that shows your local Codex chats. This page explains what the website and the app collect, and what they do not. We do not create accounts, show ads, or sell your information. The app reads Codex data only on your Mac and does not send chat content off your machine. The website uses a cookie-free visitor counter, and the app checks for updates over the internet.

The website

The littlebrain site is hosted on GitHub Pages.

Visitor analytics

The site uses Umami Cloud to count visits and understand how the site is used. Umami’s web tracker does not use cookies.

When you load a page, your browser requests Umami’s script from cloud.umami.is and sends a pageview. Clicks on the “Download for Mac” button are also recorded as a download_click event.

According to Umami, an analytics record can include the page path, referrer, browser, operating system, device type, language, screen size, and approximate location (country, region, and city). Umami says it does not store visitor IP addresses as fields in analytics records. It does process IP addresses briefly to create an anonymous visitor identifier and to estimate location. Umami and its infrastructure providers may also record IP addresses in operational or security logs, which are separate from the analytics records.

The tracker on this site is configured to ignore URL query strings and hash fragments, so values such as ?ref=hn are not sent to Umami. Tracking is limited to the smol-ninja.github.io domain.

You can read more in Umami’s FAQ, metric definitions, and privacy policy.

Downloads and GitHub

The “Download for Mac” button points to the installer on GitHub Releases. When the landing page loads, a script also asks GitHub’s API for the latest public release so the button can point to a newer installer if one exists.

Those requests go to GitHub, not to us. GitHub’s handling of that information is described in GitHub’s privacy statement.

The app

littlebrain runs on your Mac. It does not create an account, and it does not include telemetry or crash reporting.

Local Codex data

To show running chats and unread replies, the app reads Codex data that is already on your Mac. It connects to a local socket at ~/.codex/ipc/ipc.sock and reads a local catalog database at ~/.codex/state_5.sqlite. It uses this to show chat titles, status, and unread state, and to open a chat in the Codex app on your Mac.

The app stores a small local tracking file in your Application Support folder (little-brain/tracking.json) so it can remember which chats it is watching after a restart. It also saves a local preference for whether the welcome panel has been shown, and an optional “Launch at login” setting. None of this Codex or tracking data is sent off your Mac by the app.

Update checks

The app uses the Sparkle framework to check for updates. It automatically fetches a signed update feed from https://smol-ninja.github.io/little-brain/appcast.xml (hosted on GitHub Pages), by default about once a day, and whenever you click the version number in the app. System profiling is turned off, so the app does not send Sparkle’s optional hardware and system profile with those checks.

The app is set not to download or install updates automatically. If an update is available, you can install it from the app. Sparkle then downloads the installer from GitHub Releases, verifies its signature, and installs it. GitHub may process those download requests under its privacy statement.

Apart from these update checks and optional update downloads, the app’s own code does not make other network requests.

No accounts, ads, or selling

We do not ask you to create an account. We do not show advertising, and we do not sell your information.
